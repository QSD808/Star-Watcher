# Star-Watcher
A website that gives you a score for stargazing at any location and shows what planets and constellation you can see.

![example GIF](./ezgif-speed.gif)

<h3>Try it: </h3>
<a href="https://qsd808.github.io/Star-Watcher/">Press here to try it</a>

<h3>Features</h3>
1. Get a score for starwatching, based on real-time weather data, the current time, your location and the moon phase<br>
2. See which planets and constellations are visible to you.<br>
3. Get more info about planets (rise/set date, distance)<br>
4. Get more info about constellations (mini map, rise/set date and meaning)<br>
5. Locate planets and constellations using the compass
