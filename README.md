# Star-Watcher
A website that gives you a score for stargazing at any location and shows what planets and constellation you can see.

<h3>Try it: </h3>
<a href="https://qsd808.github.io/Star-Watcher/">Press here to try it</a>

<h3>Features</h3>
1. Get a score for starwatching<br>
2. The score is based on real-time weather data, the current time, your location and the moon phase<br>
3. More coming soon...<br>
